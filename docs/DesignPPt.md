# PM Slide Deck Design Guidelines & Rules

Please strictly adhere to the following design and formatting criteria when generating or refining slide presentations:

## 1. Structure & Identity
* **Anonymity**: The name of the Fellow should **NOT** be present anywhere in the slide deck.
* **Length Constraints**: 10 slides maximum (the Title slide, if you choose to have it, is counted within the 10 slides).
* **Naming Convention**: File naming format must follow: `e.g. NL PhonePe` (where `NL` represents next-leap, followed by the company/case name).
* **File Size**: Maximum file size must be less than **40 MB**.

## 2. Content & Copywriting
* **Actionable Slide Titles**: Every slide title must state the key message/takeaway of the slide. Do **NOT** use generic section titles (e.g., instead of writing "Problem", state the problem succinctly in the slide title).
* **Hyperlinking & Access**: Link all supporting research artefacts (e.g., survey URLs, design prototypes) via hyperlinks. Ensure reader access permissions are public/accessible; failure to do so results in grade reductions.

## 3. Typography & Accessibility (Strict)
* **Google Slides / PPT**: Minimum font size is **14pt**.
* **Figma (1920 * 1080px frame)**: Minimum font size is **26px**.
* **Canva (1920 * 1080px frame)**: Minimum font size is **22px**.
* **Contrast & Color-Blind Safety**: 
  * Ensure high contrast between text and background colors for readability.
  * Pick colors carefully to remain accessible to color-blind readers.
